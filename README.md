### Hi, I'm Gokul, founder of [26io Techlab](https://26io.com)

26io Techlab is an AI studio in Chennai. We build and run our own AI products, and we build custom software for companies, startups and individuals.

**Our products**

- **[Evi](https://26io.com/evi)**: your everyday AI assistant. It helps with work, study and everyday questions, looks things up on the web when you need current information, and reads the files and photos you upload.
- **[Kus](https://26io.com/kus)**: a knowledge API for small or local AI models. It searches trusted sources and returns answers with citations.
- **[Revmosys](https://26io.com/revmosys)**: watches your website like a good analyst. It tells you how many people found you, how many got in touch, and whether a jump in enquiries is real.
- **[Eta IDE](https://github.com/26iotechlab/eta-ide)**: an open-source AI code editor that plans, builds and checks every change, with local models that run on your own PC.
- **[Evi API](https://26io.com/evi-api)**: a planned AI API that students and small developers can afford. In development, not available yet.
